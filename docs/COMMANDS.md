# コマンド一覧

Flight Hub が登録するすべてのスラッシュコマンドです。

> コマンド名は実際に入力する文字列のため英語のままです。Bot 本体の画面上の
> 説明文は英語ですが、ここでは日本語で説明しています。

| コマンド | 説明 |
| --- | --- |
| `/about` | このオープンソース版について表示します。 |
| `/aircraft_guide` | 航空機ガイドを表示します。 |
| `/aps` | [管理者] 指定メンバーの発言履歴を出力します。 |
| `/backupflight` | [管理者] 予定イベントをバックアップサーバーに複製します。 |
| `/briefing` | 出発前ブリーフィングシートを送信します。 |
| `/cancel` | フライトの中止を通知します。 |
| `/checklist` | ブリーフィングのチェックリストを表示します。 |
| `/clear_logs` | [管理者] 指定したフライトログを削除します。 |
| `/close_signup` | フライトの募集を締め切ります。 |
| `/create_bus` | バスイベントを作成します。 |
| `/create_custom_bus` | テンプレートを使わずにバスイベントを自由に作成します。 |
| `/create_custom_flight` | テンプレートを使わずにフライトを自由に作成します。 |
| `/create_flight` | フライトを作成します。 |
| `/create_flighttest` | [テスト] テストサーバーとカテゴリを使ってフライトを作成します。 |
| `/create_private_flight` | スタッフ専用のフライトを作成します（顧客への通知なし・グレー色）。 |
| `/create_private_flight_template` | 保存済みテンプレートからスタッフ専用フライトを作成します（顧客通知なし）。 |
| `/dashboard` | 予定フライト・参加人数・設定状況を1枚のカードで一覧表示します。 |
| `/delay` | フライトの遅延を通知します。 |
| `/dispatch_app` | [スタッフ] 承認済みのフライト申請を選んで募集を開始します。 |
| `/duplicate_flight` | 既存のフライトを別の日時に複製して作成します。 |
| `/edit_briefing` | 送信済みのブリーフィングシートを編集します。 |
| `/edit_gamenight` | スタッフ限定ゲームナイトの内容（日時・画像・説明など）を編集します。 |
| `/editflightlog` | [管理者] 送信済みのフライトログを編集します。 |
| `/event_thread` | フライト募集メッセージ用のスレッドを手動で即時に作成します。 |
| `/export` | [マネージャー] フライトログをCSVまたはJSONで書き出します。 |
| `/find_staff` | 特定のポジションが未アサインの予定フライトを検索します。 |
| `/flight_app` | フライト／イベント開催の申請を送信します。 |
| `/flight_app_backup` | [管理者] 旧テキスト形式のフライト申請を現在のデジタル形式に変換します。 |
| `/flight_backup` | フライトログに不足している／追加のスタッフを登録します。 |
| `/flight_dashboard` | [マネージャー] 現在および予定のフライトを表示します。 |
| `/flight_log` | フライト後にフライトログを送信します。 |
| `/flight_stats_graph` | [マネージャー] フライト統計をグラフで表示します。 |
| `/flights` | 開催中のフライト一覧を表示します。 |
| `/healthcheck` | [マネージャー] Bot・データ読み込み・バックアップチャンネルの状態を確認します。 |
| `/help` | Bot のコマンドヘルプを表示します。 |
| `/host_change` | フライトのホストを変更します。 |
| `/inactive_staff` | [管理者] 過去 1 か月にフライトへ参加していないスタッフを一覧表示します。 |
| `/join` | VC に参加してメッセージの読み上げ（翻訳付き）を行うか、flight_code でサーバー開設通知を送信します。 |
| `/leaderboard` | スタッフのフライト参加ランキングを表示します。 |
| `/loa` | 休暇（LOA）システムのコマンド。 |
| `/manage_templates` | [管理者] 登録済みのフライト／バステンプレートを表示・削除します。 |
| `/manual_assign` | [管理者] スタッフの参加／不参加ステータスを手動で変更します。 |
| `/manual_log` | [管理者] 過去のフライトデータを手動入力、または既存のフライトログを編集します。 |
| `/news` | [マネージャー] お知らせの予約投稿を設定します。 |
| `/news_list` | [マネージャー] 予約投稿を一覧表示し、ID指定で取消します。 |
| `/onduty` | 勤務中ロールを付与／解除します（`roles.on_duty` を設定で指定）。 |
| `/poll` | 投票を作成します（ボタン式・リアルタイム集計・作成者が締め切り可能）。 |
| `/publish_schedule` | スケジュールを指定チャンネルへ強制的に公開します。 |
| `/recurring_flight` | 定期フライト（Discord ネイティブの繰り返しイベント）を作成します。 |
| `/recurring_flighttest` | [テスト] テストサーバーで定期フライト（Discord ネイティブの繰り返しイベント）を作成します。 |
| `/remind` | [マネージャー] 今月フライトしていないスタッフへ参加リマインダー DM を送信します。 |
| `/remind_status` | [マネージャー] 今月すでにリマインダーを受け取ったスタッフの一覧を表示します。 |
| `/request_staff` | フライト直前に不足ポジションの補充スタッフを募集します。 |
| `/restart` | [管理者] Bot を再起動します（不調時に使用）。 |
| `/restore` | [マネージャー] バックアップメッセージから flight_log.json をプレビューして復元します。 |
| `/restore_from_message` | [管理者] スタッフのメッセージ ID からフライトデータを強制復元します。 |
| `/route_stats` | 指定したルートの統計（運航回数・平均参加人数など）を表示します。 |
| `/search` | 便名・ルート・機材でフライトを検索します（予定／過去／全件）。 |
| `/selftest` | [管理者] 総合セルフ診断を実行し、管理者専用チャンネルへ結果を出力します。 |
| `/send_evaluation` | [マネージャー] 評価シートを DM で送信／予約し、予約の編集・取消を行います。 |
| `/setup` | Flight Hub を設定します（サーバー管理者のみ）。 |
| `/setup_em_permissions` | [管理者] イベントマネージャー向けコマンドを全員から見えるようにリセットします（実行時の EM／チーフ制限は維持）。 |
| `/staff_analytics` | [マネージャー] 過去 30 日間のスタッフ参加統計を集計して表示します。 |
| `/staff_gamenight` | スタッフ限定のゲームナイト／イベントを作成します。 |
| `/staff_profile` | スタッフのプロフィール、フライト参加率、ロール別統計を表示します。 |
| `/suggest_flight` | フライトをランダムに提案し、そのまま申請できます。 |
| `/test_admin` | [管理者専用] 隔離テストモードを切り替えます。本番の通知は無効になります。 |
| `/test_evaluate` | [管理者専用] テストモードで実行した全コマンドを保存・評価します。 |
| `/test_progress` | テストの達成状況を可視化して表示します。 |
| `/undo` | [管理者] 直近の `/host_change` を元に戻します。 |
| `/up` | GitHub から最新コードを取得して Bot を再起動します（スタッフサーバー／チーフのみ）。 |
| `/update` | [スタッフ] 保存データを再読み込み・検証・移行します（Bot のコードは更新しません）。 |
| `/update_ui` | 全メッセージを最新化し、DB からイベント画像を同期します。 |
