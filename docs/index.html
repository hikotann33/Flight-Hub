The flight operations hub
for your Discord server

Flight Hub runs the whole flight cycle: applications, staff recruitment, calendar events, briefing sheets, flight logs, surveys and dashboards. Fully open source, no hardcoded IDs, and it works with the emoji Discord already ships.

Features

Everything a flight server needs

One bot, one config file, 71 slash commands.

✈️

Flight creation

Templates, custom flights, private flights and native Discord repeating events. Codes, routes and aircraft are picked from autocompletes, never typed by hand.

👥

Staff signups

Recruitment cards per department (flight crew, cabin, airport, ground). Positions are assigned automatically up to the minimum staffing, with backfill requests when a slot is empty.

📡

Customer announcements

A formatted announcement in your customer server, with the check-in time, server lock, event link and mention roles. Private flights stay staff-only.

📋

Briefing & flight logs

Assign crews with a briefing sheet, run a readiness checklist, then send a flight log with per-department ratings, absentees and comments.

🔍

Surveys & evaluations

DM surveys and evaluation sheets with button ratings and comments, scheduled or on demand, with results archived for statistics.

📊

Stats & dashboards

Route history, staff participation leaderboards, activity graphs, and a one-card /dashboard of upcoming flights and configuration health.

⚙️

Guided setup

/setup detects channels and roles by name, saves everything to config/config.json, and lets you pick every colour and emoji from inside Discord.

🛡️

Safe by default

Backups of the flight log are posted to a backup channel and can be restored in one command. A /selftest command checks the whole installation.

🎮

Test server mode

Create throwaway flights on a test server and category, so new staff can learn the workflow without touching your customers.

Quick start

Running in five minutes

Python 3.11 or newer and a Discord application token are all you need.

  1. Get the code

    Fork or download the repository, then move into it.

    git clone https://github.com/your-org/flight-hub.git Flight-Hub
cd Flight-Hub

  2. Install the dependencies

    A virtual environment keeps your system Python clean.

    python -m venv venv
# Windows
venv\Scripts\activate
# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt

  3. Add your bot token

    Copy the example file and paste the token of your Discord application. The token is only read from this file, never from the code.

    cp .env.example .env
# Windows: copy .env.example .env
# then edit .env and set DISCORD_BOT_TOKEN

  4. Start the bot

    python run.py

  5. Run /setup on your staff server

    Pick the staff and customer servers, auto-detect the channels and roles by name, choose your colours and emojis, then press Save & finish and restart the bot once.

Full walkthrough, including the channel and role names the auto-detection looks for, is in the setup guide (Japanese).
